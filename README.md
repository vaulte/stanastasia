# Ravenswood Internet — Static Website

A 2000s-style university computer/browser interface designed for GitHub Pages.

## Structure

- `index.html` — browser new-tab/home page
- `repository.html` — university repository
- `research.html` — research database
- `forum.html` — student forum
- `archives.html` — university archives
- `email.html` — student email
- `map.html` — campus map
- `css/` — separated stylesheet files
- `js/main.js` — small static-site interactions
- `assets/` — images and icons

## GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

No server-side code is required.
